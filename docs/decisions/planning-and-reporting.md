## Open decisions

- 보고서·입출력 보존 기간과 저장량 제한은 LLM 기능 구현 전에 확정한다. `expires_at`은 예약 필드이며 현재 자동 삭제는 없다.
- 로컬 모델 제공자, 실행기, timeout, 재시도·중복 실행 방지와 입력량·분할 정책을 실행 기능 구현 전에 확정한다.
- 시스템 공용 스킬의 생성·배포 권한, 스킬 버전 검증·승인 UI와 SKILL.md export 형식을 스킬 관리 구현 전에 확정한다.
- 간트의 진행률 입력·상태 연동, 마일스톤 날짜 편집, 의존 순환 차단, 영업일 달력, 자동 재계획·baseline 정책은 간트 구현 전에 확정한다.
