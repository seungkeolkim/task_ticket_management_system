## UI-007 초기 MVP 화면 구성 목록

이 목록은 필요한 화면과 각 화면이 담당할 기능 범위만 정의한다. URL 구조, 메뉴 배치, 레이아웃, 탭·팝업·패널 사용 여부와 같은 상세 UI는 구현 시점에 변경할 수 있다. 관련 기능을 한 화면에 합치거나 여러 화면으로 나누더라도 아래 책임에 접근할 수 있어야 한다.

### 인증 및 공통

- 로그인
- 비밀번호 변경: 최초 로그인 또는 관리자 초기화 후 강제 변경과 사용자의 일반 변경
- 내 작업 대시보드: 내 담당·생성 티켓, 기한 정보, 최근 수정 티켓 및 미확인 멘션
- 내 프로젝트: 사용자가 접근할 수 있는 프로젝트 조회 및 선택

### 프로젝트 업무

- 티켓 목록·검색: 필터, 정렬, 페이지네이션 및 저장 필터 사용
- 티켓 상세: 목록 내 인라인 상세와 직접 접근 가능한 전체 상세를 모두 제공
- 티켓 생성·편집
- 칸반 보드

### 프로젝트 관리

- 프로젝트 기본 정보 관리
- 프로젝트 구성원 및 역할 관리
- 프로젝트 휴지통과 티켓 복구

### 시스템 관리

- 사용자 관리와 비밀번호 초기화
- 조직 계층 관리와 조직 JSON 가져오기·내보내기 및 적용 전 미리보기
- 전체 프로젝트 생성·조회·수정 및 관리 대상 프로젝트 접근

댓글, 멘션, 첨부파일, 티켓 관계와 변경 이력은 티켓 상세 책임에 포함한다. 개인·공유 저장 필터 관리는 티켓 목록과 칸반의 필터 책임에 포함하며, 현재 단계에서는 각각을 독립 화면으로 요구하지 않는다.
