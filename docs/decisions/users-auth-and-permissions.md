# User, authentication, and permission decisions

| ID | 날짜 | 상태 | 결정 | 근거·영향 |
|---|---|---|---|---|
| IAM-001 | 2026-09-16 | DECIDED | 시스템 역할은 일반 사용자와 시스템 관리자 두 종류이며 사용자는 물리 삭제 대신 비활성화한다. | 티켓 작성자와 변경 이력을 유지하면서 로그인을 차단할 수 있다. |

| IAM-005 | 2026-09-16 | DECIDED | 프로젝트 사용자는 자신이 생성했거나 현재 담당자인 티켓만 수정하고 프로젝트 관리자는 프로젝트 내 모든 티켓을 수정한다. | 일반 사용자의 업무 자율성과 프로젝트 단위 관리 책임을 함께 유지한다. |

## Open decisions

- 최초 시스템 관리자에게 연결할 초기 조직을 자동 생성할지, bootstrap 입력으로 받을지 인증 구현 전에 확정한다.
- 로그인 실패 제한의 횟수, 관찰 시간, 지연 방식은 인증 구현 시 확정한다.
- 운영 환경 session cookie의 domain 및 reverse proxy 신뢰 범위는 배포 환경이 정해질 때 확정한다.
