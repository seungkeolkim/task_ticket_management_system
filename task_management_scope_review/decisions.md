# 기능 범위 검토 결정

이 기록은 범위 검토용이며 기존 요구사항·로드맵에 아직 반영하지 않는다.

분류 기준(2026-10-03): **포함 = MVP에 포함 / 후속 = MVP 바로 뒤 / 백로그 = 시간 나면 선택적으로 검토 / 제외 = 구현하지 않음**. 기존 포함·후속 표기도 이 기준으로 읽으며 최하위 Backlog는 백로그와 같다. 방향만 확정한 A01의 구현 시점은 아직 미정이다.

## A01 — 계층과 업무 분류 분리

- 결정일: 2026-10-03
- 상태: 방향 확정, 세부 범위·구현 시점 미정
- 결정: Epic → Task → Subtask 계층을 유지하고 업무 성격을 나타내는 별도 분류 속성을 도입한다. Bug·Story 등의 업무 성격을 계층 Type에 추가하지 않는다.
- 근거: 사용자가 계층과 업무 분류를 독립적으로 관리하는 3번 방식을 선택했다.
- 구현 상태: 미구현. 코드 변경 없음.

### Open decisions

- 실제 분류 값과 기본값, 필수 여부, 단일/복수 선택
- 적용 계층, 전역/프로젝트별 관리, 관리 권한
- 입력·표시·필터·정렬·변경 이력·기존 데이터 처리 범위
- 이번 구현 범위 포함 여부와 구현 시점

개발·오류·운영·검토 및 Bug·Story는 설명용 예시이며 실제 분류 값으로 확정하지 않았다.

## A02 — 복수 Label 지원

- 결정일: 2026-10-03
- 상태: 포함(MVP), 복수 지원 확정, 세부 정책 미정
- 결정: 하나의 ticket에 여러 Label을 부여할 수 있도록 한다. 계층 Type 및 A01의 업무 분류와 별도 속성으로 관리한다.
- 근거: 사용자가 복수 Label 지원을 선택했다.
- 구현 상태: 미구현. 코드 변경 없음.

### Open decisions

- Label의 전역/프로젝트별 관리 범위와 생성·수정·삭제 권한
- 자유 입력 또는 사전 등록 방식, 이름 중복·정규화 및 삭제 시 처리
- 입력·표시·필터·검색·변경 이력 범위

## A03 — Component·업무 영역

- 결정일: 2026-10-03
- 상태: 후속
- 결정: Component·업무 영역 전용 속성은 이번 확장 범위에 포함하지 않고 후속으로 미룬다.
- 근거: 사용자가 실제로 잘 사용하지 않는 기능이라고 판단했다.
- 구현 상태: 미구현. 후속은 MVP 바로 뒤를 의미하며 Label로 대체하는 정책을 확정한 것은 아니다.

## A04 — 목표 Release·Fix version

- 결정일: 2026-10-03
- 상태: 최하위 Backlog, 일정 없음
- 결정: 이번 범위 및 일반 후속 구현 계획에서 제외하고 아이디어로만 보관한다. 다른 할 일이 없고 구현 의향이 생길 때 선택적으로 재검토한다.
- 근거: 사용자가 사실상 할 일이 없을 때 재미로 만들어 볼 정도의 낮은 우선순위를 지정했다.
- 구현 상태: 미구현. 구현 의무·목표 일정·자동 착수 계획 없음.

## A05 — 영향받는 Version

- 결정일: 2026-10-03
- 상태: 제외
- 결정: 영향받는 Version 전용 속성을 구현 범위에서 제외한다. 후속 또는 최하위 Backlog로 남기지 않는다.
- 근거: 사용자가 제외를 선택했다. 필요한 버전 정보를 기존 설명 본문에 기재하는 것은 제한하지 않는다.
- 구현 상태: 미구현. 코드 변경 없음.

## A06 — 재현 정보·Acceptance criteria

- 결정일: 2026-10-03
- 상태: 제외
- 결정: 재현 환경·재현 절차·Acceptance criteria용 별도 필드와 전용 본문 Template은 구현 범위에서 제외한다. 기존 설명 본문에 자유롭게 작성하는 기능은 유지한다.
- 근거: 사용자가 제외를 선택했다.
- 구현 상태: 추가 구현 없음. 범용 티켓 Template 기능(B16)의 포함 여부는 별도로 결정한다.

## A07 — Severity

- 결정일: 2026-10-03
- 상태: 제외
- 결정: Priority와 별도로 Severity 속성을 추가하지 않는다. 기존 Priority는 유지한다.
- 근거: 사용자가 제외를 선택했다.
- 구현 상태: 추가 구현 없음.

## A08–A15 — 일괄 결정

- 결정일: 2026-10-03
- 근거: 사용자가 항목별 분류를 직접 지정했다.
- 구현 상태: 모두 미구현 또는 기존 기반만 존재. 이번 변경은 결정 기록이며 코드 변경 없음.

| ID | 항목 | 결정 | 범위·남은 사항 |
|---|---|---|---|
| A08 | 생성자와 별도 요청자 | 백로그 | 시간 나면 선택적으로 검토 |
| A09 | 복수 담당자·협업자·Reviewer | 후속 | 상세는 후속 착수 시 논의. 복수 담당자 또는 책임자 1명+협업자 방식 중 어느 것도 아직 선택하지 않음 |
| A10 | 계획 시작일·종료일 | 후속 | 기존 DB 기반을 사용자 기능으로 연결. 구체적인 일정 규칙은 미정 |
| A11 | 시간 단위 기한 | 백로그 | 날짜 단위 기한은 유지, 시간 확장은 선택적 검토 |
| A12 | Story points | 후속 | 상대적 작업량 지원, 점수 척도는 미정 |
| A13 | 예상·남은 공수 | 제외 | 전용 시간 예상·잔여 공수 속성은 구현하지 않음 |
| A14 | Work log | 후속 | 실제 투입 시간 기록. A13 제외와 독립적이며 기록·수정·집계 정책은 미정 |
| A15 | 진행률 | 후속 | 직접 입력 또는 하위 작업 기반 계산 방식은 미정 |
