# 기능 범위 검토 결정

이 기록은 범위 검토용이며 기존 요구사항·로드맵에 아직 반영하지 않는다.

## A01 — 계층과 업무 분류 분리

- 결정일: 2026-10-03
- 상태: 방향 확정, 세부 범위·구현 시점 미정
- 결정: Epic → Task → Subtask 계층을 유지하고 업무 성격을 나타내는 별도 분류 속성을 도입한다. Bug·Story 등의 업무 성격을 계층 Type에 추가하지 않는다.
- 근거: 사용자가 계층과 업무 분류를 독립적으로 관리하는 3번 방식을 선택했다.
- 구현 상태: 미구현. 코드 변경 없음.

### Open decisions

- 실제 분류 값과 기본값, 필수 여부, 단일/복수 선택
- 적용 계층, 전역/프로젝트별 관리, 관리 권한
- 입력·표시·필터·정렬·변경 이력·기존 데이터 처리 범위
- 이번 구현 범위 포함 여부와 구현 시점

개발·오류·운영·검토 및 Bug·Story는 설명용 예시이며 실제 분류 값으로 확정하지 않았다.

## A02 — 복수 Label 지원

- 결정일: 2026-10-03
- 상태: 검토 범위 포함, 복수 지원 확정, 세부 정책·구현 시점 미정
- 결정: 하나의 ticket에 여러 Label을 부여할 수 있도록 한다. 계층 Type 및 A01의 업무 분류와 별도 속성으로 관리한다.
- 근거: 사용자가 복수 Label 지원을 선택했다.
- 구현 상태: 미구현. 코드 변경 없음.

### Open decisions

- Label의 전역/프로젝트별 관리 범위와 생성·수정·삭제 권한
- 자유 입력 또는 사전 등록 방식, 이름 중복·정규화 및 삭제 시 처리
- 입력·표시·필터·검색·변경 이력 범위와 구현 시점

## A03 — Component·업무 영역

- 결정일: 2026-10-03
- 상태: 후속
- 결정: Component·업무 영역 전용 속성은 이번 확장 범위에 포함하지 않고 후속으로 미룬다.
- 근거: 사용자가 실제로 잘 사용하지 않는 기능이라고 판단했다.
- 구현 상태: 미구현. 재검토 시점은 정하지 않았으며 Label로 대체하는 정책을 확정한 것은 아니다.

## A04 — 목표 Release·Fix version

- 결정일: 2026-10-03
- 상태: 최하위 Backlog, 일정 없음
- 결정: 이번 범위 및 일반 후속 구현 계획에서 제외하고 아이디어로만 보관한다. 다른 할 일이 없고 구현 의향이 생길 때 선택적으로 재검토한다.
- 근거: 사용자가 사실상 할 일이 없을 때 재미로 만들어 볼 정도의 낮은 우선순위를 지정했다.
- 구현 상태: 미구현. 구현 의무·목표 일정·자동 착수 계획 없음.

## A05 — 영향받는 Version

- 결정일: 2026-10-03
- 상태: 제외
- 결정: 영향받는 Version 전용 속성을 구현 범위에서 제외한다. 후속 또는 최하위 Backlog로 남기지 않는다.
- 근거: 사용자가 제외를 선택했다. 필요한 버전 정보를 기존 설명 본문에 기재하는 것은 제한하지 않는다.
- 구현 상태: 미구현. 코드 변경 없음.

## A06 — 재현 정보·Acceptance criteria

- 결정일: 2026-10-03
- 상태: 제외
- 결정: 재현 환경·재현 절차·Acceptance criteria용 별도 필드와 전용 본문 Template은 구현 범위에서 제외한다. 기존 설명 본문에 자유롭게 작성하는 기능은 유지한다.
- 근거: 사용자가 제외를 선택했다.
- 구현 상태: 추가 구현 없음. 범용 티켓 Template 기능(B16)의 포함 여부는 별도로 결정한다.
