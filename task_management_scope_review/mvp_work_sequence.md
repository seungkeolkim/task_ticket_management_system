# MVP 남은 작업 순서

2026-10-03 범위 검토와 기존 미완료 로드맵을 함께 고려하여 합의한 순서다. 구현 완료를 의미하지 않으며 기존 요구사항·로드맵의 상세 동기화는 각 구현 작업에서 진행한다.

| 순서 | 작업 | 남은 범위 |
|---|---|---|
| 1 | 복수 Label·Custom fields | 관리 범위·권한·필드 종류 확정, 입력·표시·검증·변경 이력과 기존 데이터 처리 |
| 2 | 칸반·개인·공유 필터 | 칸반 필터, 개인·프로젝트 공유 저장 필터, 저장 조건·접근 권한 검증. Label·Custom fields 연계 범위는 작업 시 논의 |
| 3 | 조직 관리 마무리 | 수정·이동·비활성화와 화면 연결, 순환 이동 차단, 소속 사용자 영향 결정 |
| 4 | 조직 JSON 입출력 | Export, Import 검증·미리보기, 전체 Transaction 적용 |
| 5 | 티켓 권한·업무 규칙 점검 | 역할별 권한 확인, 종료 잠금·의존 완료 차단의 완화 검토(C06). 실제 완화 정책은 미정 |
| 6 | 첨부파일 삭제 | 삭제 권한·즉시 접근 차단·본문 이미지 참조 처리·보존 기간 적용 |
| 7 | 보존 만료 정리 | 휴지통·첨부파일·감사 로그 정리 명령, 관리자 수동/자동 actor 구분, 실행 주기·중복 실행 방지 |
| 8 | 운영 준비·최종 검증 | CSRF·프로젝트 격리·감사 점검, HTTPS·Secure cookie·proxy, Browser 흐름, macOS Docker mount, Backup/Restore, health check·로그·배포 Checklist |

## 진행 조건

- 2026-10-03: 1번의 자유 Label·Ad-hoc Text 필드 입력·표시·저장·이력·migration과 검증을 구현했다. Text 이외 타입·선택형 확장 필드는 제외하며 다음 작업은 2번 칸반·개인·공유 필터다. 상세 진척도는 `IMPLEMENTATION_ROADMAP.md`를 따른다.

- 사용자 요청에 따라 권한·업무 규칙 점검을 조직 JSON 입출력 다음, 첨부파일 삭제 직전으로 배치한다.
- 해당 변경은 테스트하면서 개발해야 하므로 테스트 가능한 환경에서 진행한다. 그전에는 기존 권한·종료 잠금·의존성 규칙을 유지한다.
- 테스트 환경 부재를 미검증 구현의 완료 처리 근거로 삼지 않는다. 기능별 검증과 마지막 통합 검증을 구분한다.
- 당장 다음 작업은 복수 Label·Custom fields의 MVP 세부 범위를 확정한 뒤 구현하는 것이다.
- Mention·협업자·unread·계획 일정·Sprint 등은 결정대로 후속이며 이번 MVP 순서에 추가하지 않는다.
